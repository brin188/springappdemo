## 🏆 Capstone Project — Scaler Software Engineering

This repository is part of the **Scaler Software Engineering Capstone Project**.
It represents a simplified **eCommerce application** similar to Amazon, developed to demonstrate scalable backend design and service-oriented architecture principles.

### 🛒 Project Overview

The system simulates core eCommerce functionality — product browsing, ordering, payments, and notifications — implemented through a microservices architecture using **Spring Boot** and related technologies.

### 🧩 Related Repositories

This project is one of several services that together form the complete eCommerce platform:

* **[UserService](https://github.com/brin188/UserService)** – Handles user registration, authentication, and profile management.
* **[PaymentService](https://github.com/brin188/PaymentService)** – Manages payment transactions and gateway integrations.
* **[EmailService](https://github.com/brin188/EmailService)** – Sends order confirmations, OTPs, and other user notifications.
* **[APIGateway](https://github.com/brin188/APIGateway)** – Central entry point for routing requests to backend microservices.
* **[ServiceDiscovery](https://github.com/brin188/ServiceDiscovery)** – Enables dynamic service registration and discovery (Eureka).
